
# 🛠️ Dev Utils

Utilitários para facilitar o desenvolvimento e manutenção de projetos. Scripts auxiliares para automação de tarefas comuns do dia a dia.

---

## 📦 Scripts Disponíveis

### 📝 Update Changelog
**Localização**: `update-changelog/`

Script para atualizar e manter o arquivo CHANGELOG.md de forma consistente e organizada.

**Características:**
- ✅ Adiciona novas entradas ao changelog
- ✅ Mantém formato padronizado
- ✅ Organiza mudanças por tipo (Add, Fix, Change, etc)
- ✅ Interface interativa
- ✅ Preserva histórico existente

**Quick Start:**
```bash
cd update-changelog
./update-changelog.sh
```
